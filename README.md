* Test Project

* Запуск

1. Активировать venv:
.venv\\Scripts\\activate
2. Установить зависимости: pip install -r requirements.txt

* Структура

- `api_tests/` — тесты API.
- `selenium_tests/fixtures/` — фикстуры pytest.
- `selenium_tests/locators/` — локаторы элементов.
- `selenium_tests/` — веб-тесты.
