* Практическая работа 7: Создание математического теста с фикстурой

Проект содержит параметризованный тест на сложение чисел с использованием фикстуры `pytest`.

* Структура проекта

- `math_utils.py` — реализация функции `add_numbers`.
- `tests/test_math.py` — тесты с параметризованной фикстурой.
- `README.md` — текущая инструкция.

* Как запустить тесты

Для запуска тестов используйте команду:

python -m pytest -v
